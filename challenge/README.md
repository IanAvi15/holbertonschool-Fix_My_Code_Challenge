# Overview
Fix My Code Challenge is a debugging-focused project where you dive into existing codebases and correct broken or inefficient implementations. Instead of writing programs from scratch, the goal is to analyze, understand, and fix code written by someone else. This mirrors real-world software engineering, where maintaining and improving legacy code is a core skill.

Each task provides a faulty script or module in a specific programming language. Your job is to identify the issue, correct it, and ensure the program behaves as intended.

# Project Structure
The repository contains multiple challenges, each in its own file or directory. Every challenge includes:

A pre-written, buggy implementation

Expected behavior or output

Your responsibility: fix the code without rewriting it entirely

# Requirements
Allowed editors: vi, vim, emacs

Environment: Ubuntu 20.04 LTS

All files must end with a new line

A README.md is required at the root of the project

You must not recode everything—only fix what is broken

# General Approach
To succeed in this project:

Read and understand the existing code

Identify logical, syntactical, or structural issues

Apply minimal, targeted fixes

Preserve the original style and intent

Test thoroughly to confirm correct behavior
